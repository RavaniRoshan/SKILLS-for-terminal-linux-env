# SKILLS for Terminal & Linux Environment

A curated, flat, agent-readable, and capability-oriented skill library optimized for AI agents (Gemini CLI, Claude Code, Cursor, etc.).

## 🚀 Overview
This repository contains a collection of modular "skills" — procedural knowledge packages designed to enhance the reasoning and execution capabilities of AI agents. Each skill is self-contained within its own directory and follows a strict `SKILL.md` structure including purpose, rules, failure modes, and verification checklists.

## 🛠️ Key Capabilities
- **Research & Thinking**: Deep paper distillation, synthesis frameworks, systems thinking, and constraint analysis.
- **Operations & Planning**: Systematic debugging (Root Cause Analysis), vertical-slice task planning, and context engineering.
- **AI Engineering**: Context optimization, evaluation frameworks, and prompt system design.
- **Frontend & Design**: Interaction psychology, perceived performance optimization, cinematic motion, and design systems.
- **Web Development**: Specialized best practices for React, ASP.NET Core, Supabase, Stripe, and Vercel.
- **Content & Writing**: Technical specification drafting, narrative design for presentations, and knowledge packaging.

## 📁 Structure
The library uses a **flat directory structure** for maximum retrieval precision and agent reliability. No deep nesting is allowed.

## 🧩 Usage
These skills are meant to be read and followed by AI agents during a session. 
- **Direct Link**: Point your agent to specific `SKILL.md` files for domain-specific tasks.
- **Context Loading**: Add relevant skill directories to your agent's context to enforce high-quality engineering standards.

## 📦 Installation (Open Agent Skills)
Many of these skills were curated from the [Open Agent Skills Ecosystem](https://skills.sh/). You can find and add more using:
```bash
npx skills find [query]
npx skills add <owner/repo@skill>
```
