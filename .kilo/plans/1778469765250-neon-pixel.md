# Skill Marketplace Website Plan

## Project Overview
- **Project Name**: skill.rs (Skills Repository)
- **Type**: Single Page Application (React + Vite)
- **Core Functionality**: A dark-mode skill marketplace showcasing AI agent skills with search, filtering, and download capabilities
- **Target Users**: Developers looking to discover and install AI agent skills

## UI/UX Specification

### Visual Design
- **Theme**: Dark mode with cyan (#00FFFF) and white (#FFFFFF) accents on jet-black (#0A0A0A) background
- **Typography**: 
  - Headers: Bold sans-serif (Inter/Geist)
  - Code: JetBrains Mono
- **Scrollbar**: Custom styled with deep cyan (#00CED1)

### Header (Fixed)
- Left: Geometric hexagon logo "skill.rs" with subtitle "Your personal library of .skill.mt files for AI Agents."
- Right: Navigation tabs ("ALL SKILLS", "BY CATEGORY", "MY FAVORITES") + Search bar + "REPO: MySkillsRepo" status indicator with pulse animation

### Intro Banner
- "Roshan'skills ECOSYSTEM" with red-and-cyan glitch text-shadow
- Description paragraph about skills marketplace
- "AVAILABLE FOR THESE AGENTS" with cycling agent logos (fade in/out infinite animation)

### Main Content
- **Categories**: Core AI, Web Tools, Systems, Conversational, Vision, Security (6 categories, 30 skills total)
- **Skill Entry Structure**:
  - Left: Lucide-react icon
  - Center: Title (bold) + Version badge + Description
  - Right: "View .skill" button (opens modal), "Download .skill" button, 5-star ratings
  - Bottom: npx install command code snippet box

### Interactive Features
- **Search**: Real-time filtering of skills by name/category
- **View Modal**: Dark backdrop-blurred modal showing code in JetBrains Mono
- **Download**: Generates real .skill.mt/.md file and triggers browser download

## Implementation Plan

### Tech Stack
- React 18 + Vite
- Tailwind CSS for styling
- Framer Motion for animations
- Lucide React for icons

### Component Structure
```
src/
├── components/
│   ├── Header.jsx (fixed, geometric logo, tabs, search, status)
│   ├── HeroBanner.jsx (glitch text, description, agent logos carousel)
│   ├── CategorySection.jsx (labeled section with skill rows)
│   ├── SkillCard.jsx (icon, title, description, buttons, install command)
│   ├── SkillModal.jsx (code viewer modal)
│   ├── SearchBar.jsx
│   ├── NavTabs.jsx
│   └── AgentCarousel.jsx (cycling logos with fade)
├── data/
│   └── skills.js (30 skills across 6 categories)
├── App.jsx
├── main.jsx
└── index.css (custom scrollbar, global styles)
```

### Skills Database (30 entries across 6 categories)
1. **Core AI** (5): Text Generator, Code Analyzer, Semantic Search, Intent Classifier, Memory Manager
2. **Web Tools** (5): Web Scraper, API Client, Form Filler, Link Checker, Screenshot Tool
3. **Systems** (5): File Organizer, Task Scheduler, Process Monitor, Log Parser, Config Manager
4. **Conversational** (5): Chat Interface, FAQ Bot, Sentiment Analyzer, Language Translator, Name Generator
5. **Vision** (5): Image Classifier, OCR Reader, Face Detector, Barcode Scanner, Color Extractor
6. **Security** (5): Password Generator, Token Validator, Hash Calculator, SSL Checker, Input Sanitizer
