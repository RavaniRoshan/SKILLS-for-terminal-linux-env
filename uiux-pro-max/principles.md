# Cinematic UI Principles

## Scene Composition

Every interface is a scene. Treat sections as cinematic frames, not layout rectangles.

Core principles:

* **Visual hierarchy**: Lead the eye through intentional arrangement
* **Depth layers**: Foreground, midground, background separation
* **Frame within frame**: Use containers to create focus zones
* **Rule of thirds**: Asymmetric balance over centered monotony
* **Leading lines**: Guide attention through directional elements

## Temporal Pacing

Control the rate at which users consume information.

* **Hook (0-2s)**: Immediate visual anchor
* **Reveal (0.5-1.5s)**: Progressive information disclosure
* **Settle (0.3-0.8s)**: Allow comprehension after transitions
* **Transition (0.4-1.6s)**: Scene-to-scene movement

## Progressive Reveals

Never dump information. Sequence it.

1. Title anchors attention
2. Supporting copy explains
3. Visual evidence materializes
4. Interaction layer becomes available
5. Detail emerges on engagement

## Visual Tension

Create deliberate friction that resolves into clarity.

* Controlled opacity reveals
* Staggered element entrances
* Directional blur dissolve
* Scale contrast between sections

## Cinematic Framing

* Hero sections as establishing shots
* Feature reveals as close-ups
* Dashboards as tracking shots
* CTAs as climax frames

Avoid:
* Disconnected floating sections
* Repetitive 3-column grids without narrative
* Random hover effects without causality
* Decorative parallax without spatial meaning
