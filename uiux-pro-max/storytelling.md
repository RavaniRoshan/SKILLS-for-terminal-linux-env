# Storytelling Architecture

## The 7-Act Landing Page

Every page tells a story with these narrative arcs:

### 1. Hook (0-15% scroll)
Establish intrigue immediately.
- Hero with strong value proposition
- Compelling visual metaphor
- Clear differentiation
- Immediate context

### 2. Tension (15-30%)
Define the problem space.
- Pain points articulated clearly
- Current solutions fall short
- User frustration validated
- Stakes established

### 3. Mechanism (30-50%)
Introduce your novel approach.
- Core innovation explained simply
- How it works visually demonstrated
- Differentiators highlighted
- "Aha" moment engineered

### 4. Proof (50-70%)
Demonstrate effectiveness.
- Quantitative results
- Customer testimonials
- Before/after comparisons
- Social proof indicators

### 5. Workflow (70-80%)
Show the product in action.
- Step-by-step demo
- Interface walkthrough
- Key interactions highlighted
- Mental model reinforced

### 6. Trust (80-90%)
Address concerns and build credibility.
- Security certifications
- Compliance badges
- Team expertise
- Company track record

### 7. Conversion (90-100%)
Clear, compelling call to action.
- Single primary action
- Risk reversal
- Social proof reinforcement
- Urgency/scarcity (if appropriate)

## Scroll as Narrative Progression

- Each section advances the story
- Visual style evolves with narrative phase
- Motion design supports emotional arc
- Entrance animations reinforce pacing

## Content Hierarchy

1. Headline: Core promise
2. Subheadline: Mechanism summary
3. Supporting proof: Evidence
4. Visual demonstration: Proof of concept
5. Social validation: Trust signals
6. Call to action: Next step

## Never Use

- Feature dump grids without context
- "Our product does X, Y, Z" lists
- Generic stock photos
- Repetitive card layouts
- Bland testimonials
- Multiple CTAs competing for attention

## Storyboarding Process

1. Map user journey stages
2. Identify emotional highs/lows
3. Design visual progression
4. Create prototype to validate flow
5. Refine timing and transitions
6. Test comprehension at each step
