# Core Mission

Design interfaces that feel:

* cinematic
* engineered
* emotionally intentional
* spatially coherent
* temporally consistent
* narratively structured

Avoid generic SaaS layouts.

Every interaction must:

* guide attention
* communicate hierarchy
* reinforce product understanding
* increase perceived quality
* reduce cognitive entropy

# Primary Design Systems

## Narrative System

Pages are treated as cinematic timelines.

Structure:

1. Hook
2. Tension
3. Mechanism
4. Proof
5. Workflow
6. Trust
7. Conversion

Scroll is narrative progression.

---

## Motion System

Motion must:

* explain
* guide
* reinforce hierarchy
* communicate causality

Never animate for decoration alone.

Preferred stack:

* Framer Motion
* GSAP
* Motion One
* Lenis

Avoid animation spam.

---

## HyperFrames Philosophy

Interfaces are scene compositions.

Sections behave like:

* cinematic sequences
* programmable storyboards
* deterministic interaction flows

Use:

* layered motion
* progressive state reveals
* controlled pacing
* spatial transitions

---

## Interaction Philosophy

Interactions should feel:

* immediate
* precise
* physically coherent
* intentional

Use:

* spring systems
* temporal consistency
* hover anticipation
* shared transitions

Avoid:

* random easing
* inconsistent timings
* bounce-heavy interactions

---

## Frontend Standards

Optimize for:

* 60fps rendering
* GPU-safe transforms
* accessibility
* deterministic rendering
* responsive consistency

Preferred stack:

* Next.js
* Tailwind
* Framer Motion
* GSAP

Three.js only when necessary.

---

## Typography Rules

Typography defines authority.

Use:

* strong hierarchy
* whitespace rhythm
* restrained font systems
* editorial composition

Avoid:

* excessive font mixing
* oversized gradients
* decorative typography

---

## Color System

Use restrained palettes.

Preferred:

* monochrome foundations
* single accent color
* semantic state colors

Avoid:

* rainbow UI
* excessive neon
* oversaturated gradients

---

## Performance Discipline

Every visual effect has rendering cost.

Avoid:

* excessive blur
* heavy box shadows
* layout thrashing
* unnecessary WebGL

Prefer:

* transforms
* opacity
* composited layers

---

## Accessibility Standards

Always support:

* reduced motion
* keyboard navigation
* semantic HTML
* proper contrast
* visible focus states

Accessibility is mandatory.

---

## Emotional Targets

The interface should communicate:

* confidence
* precision
* clarity
* momentum
* sophistication

The goal is not visual decoration.

The goal is controlled perception.
